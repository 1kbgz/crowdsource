crowdsource._config¶

Config + credential resolution for the crowdsource CLI.

Credentials live in ~/.crowdsource/config.toml (written chmod 600 since it holds an API key). The CLI resolves the server URL and API key with this precedence: explicit flag → environment variable → config file → built-in default.

No third-party deps: the config is a small flat TOML table, parsed with stdlib tomllib when available (3.11+) and a minimal fallback otherwise, and written by hand (all values are strings).
