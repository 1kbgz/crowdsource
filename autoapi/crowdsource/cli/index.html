crowdsource.cli¶

The crowdsource command-line interface.

A terminal-first client for the crowdsource platform — the CLI is a headline feature of the product, not a test harness. It is a thin wrapper over the compiled Rust core (the pyo3 crowdsource.Client): the CLI marshals arguments, resolves credentials, and formats output; all transport/auth/typing live in Rust.

Credentials resolve flag → env → ~/.crowdsource/config.toml. Every command supports --format table|json|csv. Exit codes: 0 ok, 1 usage, 2 auth, 3 network/server, 4 insufficient credits.
